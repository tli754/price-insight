# Plan: Dashboard UI — Products, Competitors, Competitor Products, Insight

## Context

Build a simple internal admin dashboard in the existing Nuxt 4 + `@nuxt/ui` v4 frontend.
The UI uses mock data for now. Backend API integration comes in a later phase.

---

## Notes & considerations

### Nuxt version
The project runs **Nuxt 4** (not Nuxt 3). The `app/` directory convention is already in use (`app/app.vue`, `app/layouts/`, etc.).

### @nuxt/ui version
The project uses **`@nuxt/ui` v4** (free tier). All specified components (`UNavigationMenu`, `UButton`, `UCard`, `UTable`, `UInput`, `UBadge`) are available in the free tier.

### Header
The existing header in `app/layouts/default.vue` is kept unchanged. Only `AppNav` is added below it.

## Components

### `AppNav.vue`
- `UNavigationMenu` horizontal, links:
  - Products → `/products`
  - Competitors → `/competitors`
  - Competitor Products → `/competitor-products`
  - Insight → `/insight`
- White background, bottom border
- Active link highlighted via router

---

## Pages

### `/products` (`pages/products.vue`)
- `UInput` search (top right)
- `UTable` columns:
  | Column | Notes |
  |---|---|
  | Image | `<img>` thumbnail, 40×40, rounded |
  | Product Name | bold |
  | SKU | monospace text |
  | Brand | plain |
  | Price | formatted as currency |
  | Inventory | number |
  | Status | `UBadge` (draft=gray, active=green, archived=red) |
  | Actions | `UButton` "View" (xs, neutral/ghost) |

### `/competitors` (`pages/competitors.vue`)
- `UTable` columns:
  | Column | Notes |
  |---|---|
  | Logo | `UAvatar` placeholder |
  | Name | bold |
  | State | `UBadge` (active=green, inactive=gray) |
  | Matched Products | number |
  | Last Scraped | relative date string |
  | Actions | `UButton` "View" |

### `/competitor-products` (`pages/competitor-products.vue`)
- `UTable` columns:
  | Column | Notes |
  |---|---|
  | Product | product title |
  | Competitor | competitor name |
  | Competitor Title | truncated text |
  | Price | raw string |
  | Old Price | raw string, strikethrough if present |
  | Source | domain only |
  | Google Position | number badge |
  | Actions | `UButton` "View" |

### `/insight` (`pages/insight.vue`)
- 4 summary `UCard` row (grid-cols-4):
  - Total Products (number)
  - Active Competitors (number)
  - Price Changes Today (number)
  - Last Sync (timestamp)
- `UTable` columns:
  | Column | Notes |
  |---|---|
  | Product | product title |
  | Min Price | decimal |
  | Max Price | decimal |
  | Position | `UBadge` (low=green, fair=yellow, high=red) |
  | Summary | truncated text |
  | Captured At | date |

## Visual style rules

- White page background (`bg-white`)
- Table: standard `@nuxt/ui` UTable defaults
- Cards: no shadow, light border (`ring-1 ring-gray-200`)
- Spacing: `p-6` for page containers, `gap-4` between elements
- No animations beyond `@nuxt/ui` defaults
- Font: system default (no custom font)
