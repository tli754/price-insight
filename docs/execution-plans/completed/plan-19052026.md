# Plan: Redesign database schema for Shopify product catalog

## Context

Replace the current URL-extraction-based `products` table with a Shopify-product-based schema. Products come from the Shopify Products API; variant data (price, SKU, weight, inventory) is flattened into the product row. All related tables (`price_insights`, `competitor_products`, `price_history`) are simplified or updated to match the target ER diagram.

---

## Target ER diagram

```
PRODUCT ||--o{ PRODUCT_IMAGE : has
PRODUCT ||--o{ PRICE_INSIGHT : has
PRODUCT ||--o{ COMPETITOR_PRODUCT : matched_by
COMPETITOR ||--o{ COMPETITOR_PRODUCT : offers
COMPETITOR_PRODUCT ||--o{ PRICE_HISTORY : tracks
```

## Files to change

### 1. `backend/src/db/schema.ts`
- Replace `products` table definition; `external_id` as `bigint` with `index("products_external_id_idx")`; `price` and `weight` as `decimal`; add `currency`; `handle`/`title` as `varchar(500)`
- Add `productImages` table; `external_id` as `bigint`; unique index on `(product_id, external_id)`
- Replace `priceInsights` with simplified version; rename `position` → `market_position`
- Update `competitorProducts`: remove `state`, `productLinkHash`, `lastSeenAt`, `updatedAt`; add `currency`, `googlePosition`; unique index on `(product_id, competitor_id, product_link)`
- Update `priceHistory`: `extracted_price` as `decimal(12,4)`; remove `oldPrice`, `currency`; rename `observedAt` → `capturedAt`
- Export updated types

### 2. `backend/src/schemas/product.ts`
- Remove extraction Zod schemas
- Add `shopifyVariantSchema`, `shopifyImageSchema`, `shopifyProductSchema`
- Add `importShopifyProductsSchema`: `{ products: shopifyProductSchema[] }`

### 3. `backend/src/services/product-repository.ts`
- `importProducts(products: ShopifyProduct[]): Promise<number>` — upsert by `external_id`; flatten default variant (price, sku, weight, inventory_quantity); map `vendor` → `brand`; set `thumbnail` from the image where `position === 1` (fall back to `images[0].src` if none); for each image set `alt` to the Shopify alt value or the product `title` if alt is null/empty
- `listProducts(): Promise<ProductRow[]>`
- `getProductById(id: number): Promise<(ProductRow & { images: ProductImageRow[] }) | null>`
- Remove `saveExtractedProduct`, `getProductBySourceUrl`, `updateStatus`

### 4. `backend/src/routes/products.ts`
- Remove `POST /api/products/extract`, `PATCH /api/products/:id/status`
- Add `POST /api/products/import` — validate with `importShopifyProductsSchema`, call `importProducts()`, return `{ imported: number }`
- Update `GET /api/products` and `GET /api/products/:id`

### 5. `backend/src/services/competitor-analysis-service.ts`
- Update field references: `product.productName` → `product.title`

### 6. `backend/src/services/extractor-service.ts` + `backend/src/app.ts`
- Remove `ExtractorService` from bootstrap (no longer needed for own products)
